# Zairalx Desktop — downloads

This repository holds **only the installers** of the Zairalx desktop app. There is no code here.

**Download:** [zairalx.com/download](https://zairalx.com/download) — always the newest version.

- One app for every Zairalx shop: connect your shop, sign in, and you are in.
- The app updates itself: installed apps check this repository's latest release.
- Windows 10 and 11. Mac and Linux: coming soon.

## For the Zairalx team
Each version is one release here with three files: `Zairalx-Setup-x.y.z.exe`, its `.blockmap` and `latest.yml`.
How to make and publish a version: `desktop/README.md` in the main (private) repository.
Never delete old releases — installed apps and links may still use them.
